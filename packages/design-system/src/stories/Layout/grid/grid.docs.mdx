## Props

### Grid

```ts
export type GridColumns = number;
export type GridGap = keyof DefaultTheme["spacing"] | number | string | "none";
export type GridMinWidth = keyof DefaultTheme["spacing"] | number | string;

export interface GridProps {
  as?: ElementType;
  children?: ReactNode;
  columns?: GridColumns; // default: 3
  gap?: GridGap; // default: "none"
  rowGap?: GridGap;
  columnGap?: GridGap;
  responsive?: boolean; // default: false
  minWidth?: GridMinWidth; // default: 200
  fullWidth?: boolean; // default: false
}
```

### GridItem

```ts
export interface GridItemProps {
  as?: ElementType;
  children?: ReactNode;
  colSpan?: number;
  rowSpan?: number;
}
```

## Responsive

반응형 모드에서는 `minWidth`를 기준으로 컬럼 수가 자동으로 조정됩니다.

<Canvas of={GridStories.Responsive} />

```tsx
<Grid responsive minWidth={200} gap={16}>
  <Box />
  <Box />
  ...
</Grid>
```

## Row / Column Gap

`rowGap`과 `columnGap`을 개별로 지정할 수 있습니다.

<Canvas of={GridStories.WithRowGap} />

```tsx
<Grid columns={3} rowGap={24} columnGap={8}>
  <Box />
  <Box />
  ...
</Grid>
```

## GridItem Span

`GridItem`의 `colSpan`, `rowSpan`으로 셀을 병합할 수 있습니다.

<Canvas of={GridStories.ItemSpan} />

```tsx
<Grid columns={4} gap={16}>
  <GridItem colSpan={2}>
    <Box />
  </GridItem>
  <GridItem>
    <Box />
  </GridItem>
  <GridItem rowSpan={2}>
    <Box height={180} />
  </GridItem>
</Grid>
```
